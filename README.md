# On Par Event Host Pages

Next.js app for hosting On Par event floor plans, entertainment schedules, and itineraries on Vercel.

## Routes

- `/` - index
- `/floor-plans` - floor-plan maps
- `/entertainment-schedules` - entertainment schedule PNGs
- `/itineraries` - event itinerary cards

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The deployable images and event data are already copied into `public/`.
